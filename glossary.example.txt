# 용어집 예시 — 그대로 쓰지 말고 우리 팀 용어로 새로 만든다.
#
# 위치: ~/.config/meeting-notes/glossary.txt (또는 MEETING_GLOSSARY_FILE)
# 형식: 한 줄에 한 용어
#   정식표기 — 뜻 (자주 들리는 오인식 → 정식표기)
# '#'으로 시작하는 줄과 빈 줄은 무시한다.
#
# 무엇을 넣나
#   - 사내 시스템·서비스 이름, 약어 (음성인식이 한글 발음으로 옮기는 것이 가장 많이 틀린다)
#   - 팀에서만 쓰는 업무 용어, 상태 이름
#   - 자주 나오는 외래어 기술 용어
# 무엇을 넣지 않나
#   - 비밀번호·토큰·고객 정보
#   - 사람 이름 (회의록에 이름을 넣지 않는 정책이라 필요 없다)
#
# 용어집에는 회사 내부 정보가 들어가므로 공개 저장소에 올리지 않는다.

## 일반 개발 용어 (예시)
- Kubernetes — 컨테이너 오케스트레이션 (쿠버네티스/쿠베 → Kubernetes)
- Redis — 인메모리 저장소 (레디스/래디스 → Redis)
- Kafka — 메시지 브로커 (카프카 → Kafka)
- PR — 풀 리퀘스트 (피알 → PR)
- QA — 품질 검증 (큐에이 → QA)
- API — (에이피아이 → API)
- 롤백 — 배포 되돌리기 (롤 백/롤벡 → 롤백)
- 핫픽스 — 긴급 수정 배포 (핫 픽스/햇픽스 → 핫픽스)
- 멱등 — 같은 요청을 여러 번 보내도 결과가 같음 (면등/멱 등 → 멱등)

## 우리 팀 용어 (예시 — 실제로는 여기를 채운다)
- ACME Pay — 사내 결제 서비스 (애크미 페이/에크미페이 → ACME Pay)
- OMS — 주문관리시스템 (오엠에스/옴스 → OMS)
